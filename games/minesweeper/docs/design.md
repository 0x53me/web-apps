# 設計メモ
- 盤面は 1次元配列 `cells`(index = y*W + x)。各セルは mine/open/flag/n(周囲の地雷数)
- 難易度: 初級 9×9/10個、中級 16×16/40個、上級 24×16/70個
- 地雷は最初のクリック後に配置し、そのマスと周囲8マスには置かない(初手安全)
- 0のマスは再帰ではなく明示スタックで連鎖オープン
- 旗: 右クリック / タッチ長押し(450ms) / 旗モードボタン
- コード(chord): 開いた数字をクリックし、周囲の旗数が一致すれば残りを一括オープン
- ベストタイム: localStorage の `msBest0` / `msBest1` / `msBest2`
