# ツミアゲ

`index.html` 1ファイルで完結する積み上げタイミングゲーム。

## ルール
- ブロックが左右に往復している。タップ(PC はスペース / Enter)で落とす
- 下の段からはみ出た部分は切り落とされ、次のブロックはその幅になる
- まったく重ならなかったらゲームオーバー。積んだ段数がスコア
- ズレが `perfectTol` 以内なら PERFECT(ぴったり揃う)。`growAfter` 回連続すると幅が `growBy` ずつ戻る(最大は最初の幅)
- 段が増えるほど横移動が速くなる。高く積むと背景が暗くなり星が見えてくる
- タイトル画面の裏では自動プレイのデモが動く(振動はしない)

## 調整
- 難易度は `<script>` 冒頭の `CFG` で調整する(単位 U はスマホ縦で約1px)
- ベストスコアは localStorage の `tsumiage-best`
