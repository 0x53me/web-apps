# スネークゲーム

ブラウザで遊べるシンプルなスネークゲームです。

## 遊び方
1. `index.html` をブラウザで開く
2. 画面タップかスペースキーでスタート
3. 矢印キー / WASD / スワイプで操作(画面下のボタンも使えます)

エサを食べるとスコアが増えます。壁や自分の体にぶつかるとゲームオーバーです。ハイスコアはブラウザに保存されます。

## 構成
```
.
├── CLAUDE.md      # Claude Code への指示
├── README.md
├── index.html     # ゲーム本体
└── docs/          # ドキュメント
```
