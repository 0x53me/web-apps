# プルン・ラン

スマホ横画面向けの横スクロールアクション。主人公は丸いゼリーの「プルン」(オリジナル)。
走る・ジャンプ・敵を踏む・コインを集める・ゴールを目指す、というジャンルの遊び方だけを参考にし、既存作品のキャラ・名前・見た目・音楽は使わない。

## 構成
- `index.html` / `style.css`
- `js/config.js`: 調整用の値(重力・ジャンプ力・速度など)を `CONFIG` にまとめる
- `js/stage.js`: ステージの文字列マップ(`STAGES`)と `Stage` クラス
- `js/input.js`: キーボード+仮想ボタン(マルチタッチ。全タッチ点からボタン状態を毎回計算)
- `js/player.js`: 主人公の動きと AABB 当たり判定(1/4マス以下の小刻み移動で、すり抜けを防ぐ)
- `js/enemy.js`: 敵の種類(`ENEMY_TYPES`)・動き・見た目
- `js/items.js`: コイン・あわシールド・得点表示・キラキラ
- `js/fullscreen.js`: 横向きでの全画面切り替え
- `js/main.js`: 画面の拡大縮小(内部 640×360 で固定)、固定ステップ 1/120 秒のループ、カメラ、描画

## ルール
- HTML/CSS/バニラ JS(Canvas 2D)のみ。画像ファイルなし、効果音は Web Audio で生成
- 初心者が読めるよう、主な処理に日本語のコメントを付ける
