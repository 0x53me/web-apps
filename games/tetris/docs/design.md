# 設計メモ

- 盤面: 10列×20行、1マス24px。`board[y][x]` にミノ種別(I/O/T/S/Z/J/L)か null を保持
- ミノ生成: 7種バッグ方式(7種を一巡するまで重複しない)
- 回転: 行列を時計回りに回転。衝突時は x を 0,-1,+1,-2,+2 とずらす簡易ウォールキック
- 落下速度: `max(100, 800 - (level-1)*70)` ms。10ライン消すごとにレベルアップ
- スコア: 1/2/3/4ライン = 100/300/500/800 × レベル。ソフトドロップ +1/マス、ハードドロップ +2/マス
- ゴースト: 着地位置を半透明で表示
- ハイスコア: localStorage の `tetrisBest`
