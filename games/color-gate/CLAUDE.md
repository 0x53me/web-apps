# Color Gate

`index.html` 1ファイルで完結する反射神経ゲーム。

## ルール
- 自機(画面下部の円)は左右に自動で往復する
- タップ(PC はスペース / Enter)で自機の色が 赤→青→黄 の順に変わる
- 上から降ってくるゲートは1〜3色に区切られている。自機がくぐる区画と同じ色なら +1、違えばゲームオーバー
- 自機の下の小さな点は「次にタップしたときの色」
- 時間とともに落下速度・ゲート間隔・自機の移動速度が厳しくなり、区画数も増える

## 調整
- 難易度は `<script>` 冒頭の `CFG` で調整する(単位 U はスマホ縦で約1px)
- 区画数の増え方は `spawnGate()` 内の `t` のしきい値
- ベストスコアは localStorage の `color-gate-best`
