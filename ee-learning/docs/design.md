# ee-learning 設計書

## 1. 目的・前提
| 項目 | 内容 |
|---|---|
| 目的 | 自分が受けている電気電子情報系の授業の復習 |
| 利用者 | 自分のみ(将来 GitHub Pages で公開し、スマホからも見る) |
| レベル | 高専4〜5年・大学学部程度。複素数・微分方程式・ベクトル解析を使った説明も可 |
| 中心機能 | ① 解説ページ ② 動かせる教材 ③ 公式集・用語集(検索つき) |
| 対象外(当面) | クイズ・進捗管理・ログイン |
| 本文の作り方 | Claude が一般的な内容で下書き → 授業に合わせて自分で修正 |

## 2. 技術方針
- HTML/CSS/JS のみ、ビルドなし。`<script>` で順に読み込む(ES Modules は使わない)
- 外部ライブラリは CDN から2つだけ、バージョン固定
  - **marked**(Markdown → HTML)
  - **KaTeX**(数式表示。auto-render は使わず `katex.renderToString` で描画)
- 本文は Markdown ファイルを `fetch` で読む → ローカルでは Live Server / `python -m http.server` で開く
- ルーティングはハッシュ方式(`#/...`)。GitHub Pages のサブパスでも 404 対策なしで動く
- パスはすべて相対パス

### Markdown と数式の処理順
marked が `_` や `\` を強調・エスケープとして解釈して数式が壊れるのを防ぐため、
1. `$$...$$` と `$...$` をプレースホルダに退避
2. marked で HTML に変換
3. プレースホルダを戻して KaTeX で描画

## 4. ページ構成

### 4.1 ルート一覧
| ルート | 画面 | 内容 |
|---|---|---|
| `#/` | ホーム | 科目カード一覧、最近見た単元、教材一覧へのリンク |
| `#/s/<科目id>` | 科目ページ | 単元一覧(難易度タグ 基礎/標準/発展 つき) |
| `#/l/<科目id>/<単元id>` | 解説ページ | 単元の本文(メイン) |
| `#/tools` | 教材一覧 | 動かせる教材の一覧 |
| `#/tools/<教材id>` | 教材単体 | 教材を大きく表示 |
| `#/formulas` | 公式集 | 科目で絞り込み+検索 |
| `#/glossary` | 用語集 | 検索 |
| `#/search?q=...` | 横断検索 | 単元タイトル・公式・用語をまとめて検索 |

### 4.2 画面遷移
```

        ├─ 公式集
        └─ 用語集
   ※ 全ページのヘッダーに検索ボックス → 横断検索
```

### 4.3 共通ヘッダー

### 4.5 科目ページ
- 科目名・説明
- 単元一覧:タイトル、難易度タグ、使える教材のアイコン

### 4.6 解説ページ
```
┌────────────────────────────────────┐
│ ホーム > 電気回路 > 正弦波交流とフェーザ [標準] │
├────────┬───────────────────────────┤
│ 目次    │ # 正弦波交流とフェーザ        │
│ ・要点  │ ## 要点                     │
│ ・解説  │ ## 解説 (数式は KaTeX)       │
│ ・例題  │   ┌ 埋め込み教材 (rlc) ─┐    │
│ ・メモ  │   │ スライダー+グラフ    │    │
│        │   └─────────────────────┘    │
│        │ ## 例題 ▶解答を表示(折りたたみ)│

```
- 目次は本文の `##` 見出しから自動生成
- スマホでは目次が上部に移動して折りたたみ
- 本文の構成は「要点 → 解説 → 例題 → 授業メモ」で統一

## 5. コンテンツの書き方

### 5.1 目次 `content/index.json`
```json
{
  "subjects": [
    {
      "id": "circuits",
      "name": "電気回路・電磁気学",
      "desc": "直流・交流回路、過渡現象、静電界・静磁界・電磁誘導",
      "lessons": [
        { "id": "ac-phasor", "title": "正弦波交流とフェーザ", "level": "基礎", "tools": ["rlc"] }
      ]
    }
  ]
}
```
`level` は「基礎 / 標準 / 発展」の3段階。

### 5.2 単元 `content/<科目>/<単元>.md`
````markdown
# 正弦波交流とフェーザ

## 要点
- 正弦波 $v(t)=\sqrt{2}V\sin(\omega t+\theta)$ をフェーザ $\dot V = V e^{j\theta}$ で表す

## 解説
$$
\dot Z = R + j\left(\omega L - \frac{1}{\omega C}\right)
$$

<div data-tool="rlc"></div>

## 例題
**問** ...
<details><summary>解答</summary> ... </details>

## 授業メモ
(自分で追記する欄)
````
- `<div data-tool="教材id"></div>` を書くとその位置に教材が埋め込まれる
- 図は当面 SVG ファイル(`content/<科目>/img/`)か教材で代用

### 5.3 公式集 `content/formulas.md` / 用語集 `content/glossary.md`
`## 科目名` の下に `### 項目名` を並べる形式。`###` 単位で1件として検索対象にする。
```markdown
## 電気回路・電磁気学
### RL直列回路の時定数
$$\tau = \frac{L}{R}$$
関連: [過渡現象](#/l/circuits/transient)
```
LaTeX を JSON に書くとバックスラッシュのエスケープが面倒なので、公式・用語も Markdown にする。

## 7. 動かせる教材
| id | 内容 | 操作 |
|---|---|---|
| `rc` | RC/RL回路の過渡応答グラフ | R・C(L)・E をスライダー、充電/放電切替、τ を表示 |
| `rlc` | 直列RLCのインピーダンス・フェーザ図・周波数特性 | R・L・C・f を変更、共振点と Q 値を表示 |
| `opamp` | 反転/非反転増幅の入出力波形 | 抵抗値と入力振幅、飽和の様子 |
| `bode` | 1次・2次系のボード線図 | 時定数・減衰係数を変更 |
| `logic` | 論理式 → 真理値表・カルノー図 | 論理式を入力、簡単化結果を表示 |
| `base` | 基数変換・2の補数・IEEE754 | 値と基数を入力 |
| `resistor` | 抵抗カラーコード | 色帯を選択 |
| `sort` | ソートアルゴリズムの可視化 | アルゴリズム選択、ステップ実行 |
| `sampling` | 標本化・エイリアシングの可視化 | 信号周波数と標本化周波数を変更 |

各教材は `registerTool(id, { title, desc, mount(el) })` で登録する。グラフは canvas で自前描画し、色は CSS 変数(`--plot-*`)から取ってダークモードに追従させる。
スライダー・切替ボタン・結果表示・グラフ描画などの共通部品は `js/tools/registry.js` の `ToolKit` にまとめる。

実装済み:`rc` / `rlc` / `logic`(クワイン・マクラスキー法で最小積和形、ドントケア対応)/ `base`(整数+IEEE 754 単精度)

## 8. 実装ステップ
1. 骨組み:`index.html`・スタイル・ルーター・Markdown+KaTeX 描画・目次 JSON 読み込み
2. 解説ページ:見出し目次、前後リンク、教材埋め込み
3. 教材:`rc` → `rlc` → `logic` → `base` の順で作り、残りは後から追加
4. 公式集・用語集と横断検索
5. 単元本文の下書き(1科目ずつ。ユーザーが確認・修正)
6. GitHub Pages 公開(web-apps リポジトリの Pages 設定。公開 URL は `.../ee-learning/src/`)
